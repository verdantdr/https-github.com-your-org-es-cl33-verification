\section{Methods}
\label{r9:sec:main}

Every finite-dimensional and symbolic claim of \cref{r1:sec:main,r2:sec:main,r3:sec:main,r4:sec:main} is checked by a Python script
in \texttt{investigations/two\_readings/verify/}, using \texttt{numpy}, \texttt{sympy} and \texttt{scipy} only. Each script prints one line
\texttt{PASS <id>: <claim>} or \texttt{FAIL <id>: <claim>} per claim and exits with status zero only if every check passes; the sections
cite the identifiers. The derivation scripts \texttt{r1\_lagrangians.py}, \texttt{r2\_fourmomentum.py}, \texttt{r3\_octants.py} and
\texttt{r4\_bridge.py} were written with the sections. The scripts \texttt{s1\_check.py}, \texttt{s2\_check.py} and \texttt{s3\_check.py}
are independent re-checks written by adversarial referees, who did not import the derivation scripts and used different methods where
possible (other bases, rank computations over the rationals instead of eigenvalues, symbolic instead of numerical verification); where a
referee found a claim false, the corrected statement was checked and the section corrected.

Algebraic identities are checked in exact arithmetic: the generators of the realisation of Appendix~A of \cite{ES17} are signed
permutation matrices, and dimensions of commutants, intertwiner spaces and invariant forms are exact ranks of integer or rational linear
systems. Lagrangian variations, Euler--Lagrange equations, Noether currents, stress tensors and Maxwell's equations are derived on general
symbolic fields; the Grassmann-valued Dirac field is handled by an exact Grassmann jet algebra. Floating point is used only for numerical
integrations and random tests, with the tolerance stated at each check. The command
\begin{center}
\texttt{python3 investigations/two\_readings/verify/run\_all.py}
\end{center}
runs every script and writes a summary to \texttt{verify/RESULTS.md}.
